UI Lab ships in two parts:

|Part|What it is|How you get it|
|:-|------|------|
|**Components**|Primitives such as `Button`, `Dialog` and `Table`, built on Base UI|The `uilab-core` npm package. Import them, don't copy them.|
|**Blocks**|Higher-level pieces such as Data Table, Data Grid and Tour|The UI Lab [shadcn registry](https://ui.shadcn.com/docs/registry). The CLI copies the source into your project so you can change it.|

Blocks are built from `uilab-core` components, so set up the package first, then the registry.

## Starting a new project

The quickest start is a template that already has everything below set up:

```bash
npx gitpick https://github.com/ailab-core/uilab/tree/main/examples/template-vite-tanstack-router [your_project_name]
cd [your_project_name]
npm install
npm run dev
```

- [Vite Template - TanStack Router App](https://github.com/ailab-core/uilab/tree/main/examples/template-vite-tanstack-router)
- [Vite Template - TanStack Start App](https://github.com/ailab-core/uilab/tree/main/examples/template-vite-tanstack-start)

Our projects use [TanStack Router](https://tanstack.com/router/latest) or [TanStack Start](https://tanstack.com/start/latest). Some blocks, such as Data Table, need TanStack Router.

## Manual setup

Your project needs React 19, TypeScript, [Tailwind CSS v4](https://tailwindcss.com/docs/installation/using-vite) and an `@/*` path alias pointing at your source folder.

<Steps>
<Step>
### Install uilab-core

```package-install
npm install uilab-core cn tw-animate-css lucide-react
```
</Step>
<Step>
### Import the styles

Add the styles to your main CSS file, after Tailwind:

```css title="src/styles.css"
@import "tailwindcss";
@import "tw-animate-css";
@import "uilab-core/styles.css";
@import "uilab-core/default.css";

/* Make sure to add this too for themes */
@custom-variant dark (&:is(.dark *));
```

`default.css` is the theme. See [Styling](/docs/styling) to change the brand color, radius and fonts.
</Step>
<Step>
### Use a component

```tsx
import { Button } from "uilab-core"

export function Save() {
  return <Button>Save</Button>
}
```

That's all you need for components. Continue below to use blocks.
</Step>
</Steps>

## Registry setup

Blocks are installed with the [shadcn CLI](https://ui.shadcn.com/docs/cli) from the UI Lab registry at `https://ui.ailab.mn/r`.

<Steps>
<Step>
### Add a components.json

The CLI reads `components.json` at your project root to know where to put files. Create it, or add the `registries` entry if you already have one:

```json title="components.json"
{
  "$schema": "https://ui.shadcn.com/schema.json",
  "style": "base-mira",
  "rsc": false,
  "tsx": true,
  "tailwind": {
    "config": "",
    "css": "src/styles.css",
    "baseColor": "neutral",
    "cssVariables": true
  },
  "iconLibrary": "lucide",
  "aliases": {
    "components": "@/components",
    "ui": "@/components/ui",
    "lib": "@/lib",
    "hooks": "@/hooks",
    "utils": "@/lib/utils"
  },
  "registries": {
    "@uilab-core": "https://ui.ailab.mn/r/{name}.json"
  }
}
```

Point `tailwind.css` at the CSS file from the manual setup. The `aliases` decide where block files go and how their imports are rewritten.
</Step>
<Step>
### Add a block

```package-install
npx shadcn@latest add @uilab-core/data-table
```

The CLI copies the block's files into your project, installs its npm dependencies and adds any blocks it depends on. Data Table, for example, lands in `components/data-table/`, `hooks/` and `lib/`:

```tsx
import { DataTable } from "@/components/data-table/data-table"
import { useDataTable } from "@/hooks/use-data-table"
```

You can add several at once: `npx shadcn@latest add @uilab-core/data-grid @uilab-core/tour`.
</Step>
</Steps>

### Updating a block

Block files are yours after you install them. To pull the latest version, preview what would change, then overwrite:

```bash
npx shadcn@latest add @uilab-core/data-table --dry-run
npx shadcn@latest add @uilab-core/data-table --overwrite
```

`--overwrite` replaces your local copy, so commit or back up your changes first.

## TypeScript support

All components are written in TypeScript and include complete type definitions:

```tsx
import { Button, type ButtonProps } from "uilab-core"

function MyButton(props: ButtonProps) {
  return <Button {...props} />
}
```

## Framework compatibility

`uilab-core` and the blocks are client components. They work in any React app, including TanStack Router and TanStack Start.

React Server Components are not supported yet. Calling `cn` from a server component logs an error that it must run in a client component.
