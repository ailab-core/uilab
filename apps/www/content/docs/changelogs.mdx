## October 2026 - New blocks and one theme file

Released as `uilab-core@0.4.5`.

New component:
- [Questionnaire](/docs/components/questionnaire): one question at a time, with progress

New blocks:
- [Data Grid](/docs/blocks/data-grid): editable, spreadsheet-like grid
- [Tour](/docs/blocks/tour): step-by-step product tour

Updated:
- [Data Table](/docs/blocks/data-table): rebuilt with sorting, filters and view options. It needs TanStack Router.
- All components updated to the latest shadcn and Base UI.
- [Get started](/docs/get-started) and [Styling](/docs/styling) rewritten to be shorter.

Performance update:
- [uilab-core](https://www.npmjs.com/package/uilab-core): Now uses
[rolldown](https://rolldown.rs/) which is a build tool that is rolldown but
rewritten in rust.

### Theme file renamed

`neutral.css` and `legacy.css` are gone. There is now one theme file, `default.css`. Update your CSS:

```css
@import "uilab-core/styles.css";
@import "uilab-core/default.css";

/* Remove these old lines:
	@import "uilab-core/neutral.css";
	@import "uilab-core/legacy.css";
*/
```

To use your own brand colors, see [Styling](/docs/styling).

### New theme

If you are going to update the package to the latest version, you will
encounter a problem that says `uilab-core/theme.css` is not found or something
like that.

You need to update your css file like below

```css
@import "uilab-core/styles.css";
@import "uilab-core/neutral.css";

/*
	This is the old source, you can remove this line
	@import "uilab-core/theme.css";
*/
```

If you don't like the new theme, you can always use the old one with this line
```css
@import "uilab-core/styles.css";
@import "uilab-core/legacy.css";
```
