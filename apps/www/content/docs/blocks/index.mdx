Components (`Button`, `Dialog`, ...) come from the `uilab-core` package and you import them.
**Blocks** are bigger features built from those components. The CLI copies their source into your project, so you can change anything.

```package-install
npx shadcn@latest add @uilab-core/data-table
```

First time? Connect the registry once in [Get started](/docs/get-started#registry-setup).

## Which table should I use?

|If you need to...|Use|
|:-|:-|
|Show records, filter them and share the filtered link|[Data Table](/docs/blocks/data-table)|
|Let users edit cells in place, like a spreadsheet|[Data Grid](/docs/blocks/data-grid)|
